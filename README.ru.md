## 🚀 Ключевые особенности

- **Данные в реальном времени**: Получает актуальную статистику COVID-19 из Университета Джонса Хопкинса через API disease.sh
- **Мультиязычная поддержка**: Принимает названия стран на английском, русском и других языках  
- **Умная логика запасных вариантов**: Автоматически переключается между данными за сегодня/вчера, когда API возвращает нулевые значения
- **Валидация данных**: Корректно обрабатывает null/undefined значения, заменяя их на "Нет данных"
- **Пользовательский интерфейс**: Интерактивная клавиатура с флагами, ответы с эмодзи
- **Обработка ошибок**: Надежная логика повторных попыток при сбоях API и неверных названиях стран

## 🛠 Технический стек

- **Runtime**: Node.js
- **Фреймворк**: Telegraf (фреймворк для Telegram-ботов)
- **Интеграция API**: disease.sh (данные Университета Джонса Хопкинса)
- **Обработка данных**: Кастомное форматирование с toLocaleString() для читаемости
- **Окружение**: dotenv для безопасного управления токенами
- **Разработка**: nodemon для автоматической перезагрузки

## 🎯 Вызовы и решения

### Вызов 1: Миграция API
**Проблема**: Библиотека `covid19-api` устарела и возвращала HTML-ошибки вместо JSON.
**Решение**: Перешла на прямую интеграцию с API disease.sh, реализовав кастомную обработку HTTPS-запросов с корректным управлением ошибками.

### Вызов 2: Точность данных  
**Проблема**: Многие страны сообщают о 0 новых случаях за "сегодня" из-за задержек в отчетности.
**Решение**: Реализовала интеллектуальный запасной вариант, используя данные за вчера, когда сегодня возвращает 0, обеспечивая пользователям актуальную статистику.

### Вызов 3: Мультиформатный ввод
**Проблема**: Пользователи вводят названия стран с флагами (🇺🇸 США), разным регистром или разными вариантами написания.
**Решение**: Создала комплексный словарь маппинга с 100+ псевдонимами стран и конвертацией флагов в названия.

## 📊 Пайплайн обработки данных

1. **Очистка ввода**: Удаляет эмодзи-флаги, спецсимволы, нормализует регистр
2. **Маппинг стран**: Обширный словарь, поддерживающий 100+ стран на нескольких языках  
3. **API-запрос**: Прямой HTTPS-вызов к disease.sh с логикой повторных попыток
4. **Валидация данных**: Проверка на null/NaN/undefined перед форматированием
5. **Форматирование ответа**: Структурированный Markdown-вывод с таймстемпами

## 🌟 Примеры использования

Пользователи могут взаимодействовать с ботом через:
- Нажатия кнопок: 🇺🇸 США, 🇷🇺 Россия, 🇰🇿 Казахстан

## 🚀 Деплой

### Railway (Рекомендуется)
1. Запушить код на GitHub
2. Подключить Railway к репозиторию
3. Добавить переменную окружения `BOT_TOKEN`
4. Автоматический деплой

### Render
1. Создать новый Web Service
2. Подключить GitHub-репозиторий
3. Установить команду сборки: `npm install`
4. Установить команду запуска: `npm start`
5. Добавить переменные окружения

### Fly.io
1. Установить flyctl: `brew install flyctl`
2. Залогиниться: `fly auth login`
3. Инициализировать: `fly launch`
4. Установить секрет: `fly secrets set BOT_TOKEN=your_token`
5. Деплой: `fly deploy`
